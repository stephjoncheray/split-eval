💾 Sauvegarde et Restauration

Enregistrez votre espace de travail (données DEPP, Pronote et Siècle) pour reprendre votre analyse plus tard sans avoir à tout réimporter.

1. Initialisation des effectifs (Import Pronote)

Pour charger les effectifs depuis Pronote :
  1. Dans Pronote (Menu Ressources > Élèves), affichez tous les élèves de l'établissement.
  2. Assurez-vous d'afficher les colonnes : Nom, Prénom, Classe, Sexe (ou Civilité) et Étab. d'origine.
  3. Sélectionnez tous les élèves affectés dans une classe et cliquez en haut à droite sur copier les donénes en csv.
  4. Collez les données (Ctrl+V) dans la zone ci-contre.

2. Importation des résultats (Fichier DEPP)

Importez le fichier excel dans le menu établissmeent du site Restitution de la DEPP.

Traitement des Fichiers PDF & Publipostage

Réorganise les fiches DEPP et génère les archives pour le publipostage (Portail DEPP).

💡 Assistant Publipostage (Thunderbird)

Pour envoyer automatiquement les PDF générés aux familles, utilisez le logiciel Thunderbird avec l'extension Mail Merge (ou sa fonction de publipostage native). L'outil ci-dessous génère tout ce dont vous avez besoin.

  • Assurez-vous d'avoir importé le fichier Siècle (Onglet Configuration) pour récupérer les emails.
  • L'archive ZIP contiendra directement un fichier de base de données au format .csv prêt à être utilisé dans Thunderbird.
  • Important : Extrayez bien le fichier .csv ET les PDF dans le même dossier sur votre ordinateur.
